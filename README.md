# powercrawl

This project is a Node.js + Express UI for extracting B2B directory URLs. It can be hosted as:

- A full backend + frontend app on Railway
- A static frontend on Netlify with the backend served from Railway

## Railway Deployment

1. Push this repo to GitHub.
2. Create a new Railway project and connect the repository.
3. Railway will detect `package.json` and use `npm start`.
4. Set environment variables in Railway:
   - `ANTHROPIC_API_KEY` (required)
   - `PORT` (optional; Railway sets one automatically)
5. Deploy and open the Railway app URL.

This app serves `index.html` and the API endpoints from the same server.

## Netlify + Railway Deployment

1. Deploy this repo to Netlify as a static site.
2. Configure Netlify to publish from the repository root (`.`).
3. Use `echo 'No build required'` as the build command.
4. After your Railway backend is live, update `netlify.toml` and replace:

   ```toml
   to = "https://<your-railway-app>.up.railway.app/api/:splat"
   ```

   with your actual Railway app URL.
5. Deploy the Netlify site.

Netlify will proxy calls from `/api/*` to your Railway backend.

## Notes

- The backend uses `express.static(__dirname)` to serve the UI and API from the same app.
- `config.json` and `leads.txt` are runtime files generated by the server.
- The app now supports `process.env.PORT` for Railway.
- CORS is enabled on the backend to allow frontend requests from static hosts.
